# EndoScan — Endometriosis Assessment & Machine Learning Research

**An academic research project combining exploratory machine learning with an interactive symptom-assessment prototype.**

Developed in connection with the **2026 HSIL Hackathon**. This repository preserves the project's research experiments and its EndoScan web interface.

> **Research prototype only.** EndoScan is not a validated diagnostic tool, medical device, or substitute for professional medical assessment. Scores shown in the interface are heuristic and must not be interpreted as calibrated probabilities of disease.

## Project at a glance

| Research component | Approach |
| --- | --- |
| Experimental risk modeling | XGBoost classification on synthetic clinical records |
| Model evaluation | Five-fold cross-validation, recall, precision, F1, ROC-AUC, calibration |
| Exploratory pattern discovery | KMeans clustering and silhouette evaluation |
| Visualization | PCA, cluster feature plots, exploratory charts |
| Statistical exploration | ANOVA and chi-square tests |
| Web prototype | Interactive HTML/CSS/JavaScript questionnaire and results dashboard |

## EndoScan interface

The browser-based prototype includes a structured symptom questionnaire, an interactive anatomical illustration, and an assessment-results dashboard. A separate **Clinical Decision Support** tab presents rule-based summaries.

**Important implementation detail:** The `endoscan.html` interface uses JavaScript scoring and conditional rules (`calcEndoRisk()` and `assignCluster()`). It does **not** call the saved Python XGBoost or KMeans models to produce the displayed assessment. Its four displayed profiles and associated percentages are predefined interface content, not independently validated clinical subtypes.

## Research datasets

- **Synthetic clinical dataset (10,000 records):** Used for initial supervised learning and clustering experiments. Included simulated variables such as age, BMI, chronic pain, menstrual irregularity, hormonal abnormalities, infertility, and diagnosis.
- **ROXWELL baseline dataset (699 records):** Used for exploratory analysis of pain, functional impact, and psychological measures. Exploratory clusters should not be treated as clinically validated subtypes.
- **TCGA-UCEC:** A uterine/endometrial cancer dataset explored as a separate comparison/proxy. **It is not an endometriosis cohort** and does not validate endometriosis risk prediction.

Dataset access and reuse may be restricted. Raw datasets are not distributed in this repository.

## Experimental results

The following are **historical results from the synthetic-data XGBoost experiment**, not clinical performance estimates:

| Metric | Approximate result |
| --- | ---: |
| Recall | 0.880 |
| Precision | 0.454 |
| F1-score | 0.599 |
| ROC-AUC | 0.640 |

An exploratory two-cluster ROXWELL analysis reported a silhouette score of approximately **0.212**, indicating weak cluster separation. These results are from separate experiments and should not be combined as a single validated pipeline.

### View the interface

Open `endoscan.html` in a browser, or use the **Live Server** extension in VS Code. The interface itself runs in the browser. Its assessment output is generated by JavaScript rules rather than the Python ML artifacts.

### Python research scripts

The repository also contains separate Python research scripts under `src/`. To explore them locally, create a virtual environment and install the libraries required by the specific script. The project has used `pandas`, `numpy`, `scikit-learn`, `xgboost`, `scipy`, `matplotlib`, and `shap`.

**Reproducibility note:** This repository does not currently provide a verified end-to-end training command or bundled research datasets/model artifacts. Individual scripts may require original data files and environment-specific setup.

## Limitations and responsible use

- Synthetic-data classification results do not demonstrate diagnostic performance in real patients.
- Exploratory KMeans clusters are not established medical subtypes; low silhouette separation limits interpretation.
- The browser assessment uses hand-set weights, thresholds, and profile descriptions, not a validated diagnostic model.
- The interface's subtype prevalence and mental-health percentages have not been independently verified here against the underlying source data.
- TCGA-UCEC is cancer data, not an endometriosis cohort.
- No medical or treatment decision should be made from the website's scores or recommendations.

## Research context

Prepared as part of endometriosis-focused academic research associated with **HSIL Hackathon 2026**. The project explores how supervised learning, unsupervised pattern analysis, and an accessible interface can be used in a research workflow while illustrating important limitations of clinical ML.
