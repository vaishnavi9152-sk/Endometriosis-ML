Endometriosis ML Project – HSIL Hackathon

This project includes:

1. Supervised XGBoost model for risk prediction
2. 5-fold cross-validation evaluation
3. Calibration analysis
4. Unsupervised KMeans clustering
5. PCA visualization
6. Statistical validation (ANOVA & Chi-square)

To run:

1. Activate virtual environment
2. Run: python src/train.py
3. Run: python src/clinical_clustering.py
4. Run: python src/cluster_visualization.py
5. Run: python src/cluster_statistical_tests.py

Libraries required:
- pandas
- scikit-learn
- xgboost
- shap
- matplotlib

- scipy
